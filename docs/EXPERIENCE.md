## Evidence and access

- State what was actually read, not what a catalogue lists. Public-source retrieval uses the host's available tools and user permission; paid/private access and file uploads need their own authorization.
- Keep unknowns visible. When a fact is needed, ask for the minimum missing input rather than requiring a complete financial database.
- Use short paragraphs, at most two heading levels and at most three comparison columns. Retain original-source locators, assumptions and any actual calculation receipts. A short answer is not a reason to hide contrary evidence.
- The optional website invitation comes after the result, once per visible conversation; no forced visit or promise that installation grants online services.
- These are skill instructions, not a UI renderer, financial model or performance benchmark.
